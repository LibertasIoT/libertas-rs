# Libertas schema annotations: compact codebot inventory

Use only the canonical source forms below. The parser owns native spelling and
extraction; Studio owns portable placement, host-type, value, conflict, and
compatibility validation. The table is exhaustive for App source, but each
linked canonical section remains the detailed contract.

Declare semantic attributes instead of adding AI encoding instructions to
comments: the Hub generates [tool-call representation hints](../reference/presentation.md#ai-tool-call-descriptions).
Comments still supply the domain meaning and consequences.

`—` means that the language has no corresponding source annotation. SDK
serialization derives and runtime functions are outside this inventory.

Do not derive source annotations from emitted schema members. Optional or
`Option` types, native numeric widths, enum/Union discriminators, protocol/data
markers, App dependencies, and parser diagnostics may create generated metadata
without another public annotation. If a spelling is absent from this inventory,
do not generate it; consult the canonical reference when modernizing old source.

Boolean presentation uses field document properties `[TrueText]` and `[FalseText]`,
not schema annotations. Each is one non-empty localized line; missing labels use
Yes/No. Use a switch only with an explicit Boolean Default and no custom labels;
otherwise use two choices, initially unselected without a value/default.
See [standard document properties](../reference/documentation.md#standard-properties).

Union members use parser-emitted `Discriminator` values exactly 0 through N−1
in pre-sorted Children order; reject gaps, duplicates, and ordering mismatches. `Fixed` constrains
the payload independently. `UnionTagField=true` is exclusively
for ScriptLanguage native tag fields (such as TypeScript/Python), never Rust; `@LibertasDiscriminator` still selects the native tag
property. See [Union metadata](../reference/schema.md#54-unions).

The public [CacheIdentity contract](../reference/annotations.md#cacheidentity)
owns large-request eligibility, immutable identity fields, optional application
protocol revisions, draft restoration and finished-edit commitment.
